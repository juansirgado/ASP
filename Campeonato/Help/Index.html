Manual do sistema Campeonato



Como participar:
- Incluir uma aposta selecionando o campeonato na tela de 'Aposta'.
- Atualizar os palpites de gols para cada jogo/equipe na tela de 'Palpite' selecionando a aposta cadastrada.
- Uma mesma pessoa pode incluir várias apostas, mas deve atualizar os palpites para cada uma delas.
- Todas as outras telas de cadastro e a de classificação são de uso do administrador mas os usuários podem consultar as informações.
- Com os relatórios você pode acompanhar as classificação das equipes, apostas, etc

Observações:
- * Campos que são seqüências automáticas, na inclusão o sistema coloca o próximo número automaticamente.
- Todas as telas podem ser pesquisadas pelo código.
- Todas as telas com nome podem ser pesquisadas por ele.
- Na pesquisa por nome não precisa informar o nome completo, pode-se informar apenas uma parte deste que seja única.



Boa sorte, abraços.
